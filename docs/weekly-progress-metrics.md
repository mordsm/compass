# מדדי התקדמות שבועיים — Compass

Compass מחשב את המדדים באופן דטרמיניסטי מתוך הרשומות הקיימות. אין כאן הערכה של מודל שפה ואין הזנה ידנית של ציון.

## API

```http
GET /api/progress/weekly?user_id=moshe&week_start=2026-11-02
```

`week_start` הוא תאריך כלשהו בשבוע המבוקש; Compass מנרמל אותו ליום שני ומחזיר טווח של שני–ראשון. אם הפרמטר חסר, נבחר השבוע הנוכחי.

## המדדים

| מדד | חישוב | שימוש |
|---|---|---|
| `tasks_completed` | משימות בסטטוס `completed` או `done` שעודכנו בשבוע | תפוקה בפועל |
| `tasks_touched` | כל המשימות שעודכנו בשבוע | בסיס שיעור ההשלמה |
| `task_completion_rate_pct` | הושלמו ÷ עודכנו × 100 | שיעור סגירת עבודה |
| `planned_days` | מספר הימים הייחודיים עם תוכנית יומית | עקביות תכנון |
| `planning_coverage_pct` | ימי תכנון ÷ 7 × 100 | כיסוי שבועי |
| `outcomes_planned` | סך התוצאות שהוגדרו בתוכניות היומיות | היקף מיקוד מתוכנן |
| `overdue_open_tasks` | משימות פתוחות שמועד היעד שלהן חלף עד סוף השבוע | עומס וחסמים |
| `pending_approvals` | בקשות אישור שעדיין ממתינות | צוואר בקבוק בהחלטות |
| `training_sessions_completed` | אימוני מיומנות שהושלמו בשבוע | עקביות אימון |

## כללי פרשנות

- `0%` אינו בהכרח כישלון: אם לא עודכנו משימות, המכנה הוא אפס והדוח מחזיר `0.0` במקום להמציא ציון.
- מדדים מתארים פעילות שנרשמה ב־Compass בלבד; פעילות חיצונית שלא סונכרנה אינה נספרת.
- אין יעד קשיח אוניברסלי. יעדים שבועיים ייקבעו בנפרד לאחר שבוע בסיס אחד של נתונים אמיתיים.
- החלטות, אישורים ופעולות חיצוניות נשארים כפופים לכללי הבטיחות של Compass.
